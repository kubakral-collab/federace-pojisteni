# Federace Pojištění 0.26.1

## Novinky

- Přehled pro pojišťovnu lze nově vytvořit jako PDF dokument podle používaného vzoru pojišťovny.
- Po aktualizaci se při prvním přihlášení zobrazí přehled nejdůležitějších změn v nové verzi.

## Vylepšení

- Potvrzení při zakládání nového pojistného roku je lépe čitelné a má zřetelně oddělené pozadí.
- Výběr dalšího nebo volného evidenčního čísla je kompaktnější a přehlednější.
- Z uživatelského rozhraní byly odstraněny interní vývojářské poznámky; užitečné nápovědy zůstaly zachované.

## Opravy

- Změna sazby pojistného se nyní automaticky promítne do odpovídajících pojištěnců stejného pojistného roku, aniž by změnila dřívější roky nebo již uhrazené částky.
- PDF přehledu pro pojišťovnu zachovává používané rozložení, tabulku, souhrny, podpisovou část a vícestránkový výstup.
