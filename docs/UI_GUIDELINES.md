# UI pravidla

- jednoduchost pro málo zkušeného uživatele; levé menu pro moduly; detail člena jako centrum akcí osoby;
- zachovat jednoklik v seznamu, jasné Zpět a kontext filtrů; bez fotografií a zbytečných modálů;
- nezobrazovat technické názvy ani `0/1`; používat češtinu a srozumitelné symboly;
- `OdbPříslušnost` = „Odborová příslušnost“, `Ztráta` = „Pojištění ztráty“;
- PDF zachovává schválený vzhled Access sestav a A4;
- návrhy se implementují až po schválení Product Ownera.
