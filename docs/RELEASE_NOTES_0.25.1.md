# Federace pojištění 0.25.1

## Novinky

- Modernizovaná elektronická přihláška s přehlednějšími kroky a rekapitulací.
- Volba dalšího evidenčního čísla nebo dostupného čísla z mezery v současné evidenci.
- Nastavení velikosti písma celé aplikace na 100 %, 110 %, 125 % nebo 150 %.
- Hromadné potvrzení členů organizace do jednoho PDF souboru.

## Vylepšení

- Tisk prázdné i dokončené přihlášky používá standardní tiskový postup Windows.
- Nový pojištěnec je dostupný hned pod Hlavním panelem.
- Organizaci pro hromadná potvrzení lze vybrat z nabídky.
- Potvrzení o pojištění používá aktualizovanou třistránkovou podobu pro rok 2026.

## Opravy

- Elektronická přihláška správně přijímá všechny aktuální limity včetně 500 000 Kč a 600 000 Kč.
- Opraveno otevření seznamu nezaplacených pojistek z hlavního panelu.
- Zvolená velikost písma se zachová po restartu aplikace.
