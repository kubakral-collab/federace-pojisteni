# Federace pojištění 0.26.0

## Novinky

- Ruční založení nového pojistného roku.
- Přepínač aktivního pojistného roku na Hlavním panelu.
- Souběžná práce s více pojistnými roky.
- Automatický převod pojištěnců při ručním založení roku.
- Evidence skutečného ukončení pojištění.
- Samostatné okno detailu pojištěnce.
- Ochrana neuložených změn.

## Vylepšení

- Přehled pro pojišťovnu podle data počátku pojištění.
- Názvy hromadných potvrzení obsahují rok a organizaci.
- Názvy individuálních dokladů obsahují rok, jméno a příjmení.
- Možnost upravovat archivní pojistné události.

## Opravy

- Opraveno načítání Přehledu pro pojišťovnu.
- Opraveno zavírání detailu člena po uložení.
- Opraven systémový tisk přihlášky.
- Odstraněno automatické zakládání pojistného roku k 1. lednu.
